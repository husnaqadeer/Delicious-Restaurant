# Delicious Restaurant

## Project Description

Delicious Restaurant is a responsive restaurant website created to provide information about the restaurant, its popular dishes, opening hours, and table reservations.

## Technologies Used

* HTML
* CSS
* JavaScript
* Git
* GitHub

## Features

* Restaurant navigation
* Hero image
* Popular dishes section
* About section
* Opening hours
* Reservation form
* JavaScript form validation
* Responsive design for mobile, tablet, and desktop
